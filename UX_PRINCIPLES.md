# User experience contract

AI-first, never AI-only. Make the three modes visible and preserve the same project when switching. Manual controls remain reachable without model setup or connectivity. Director provides outcome; Approver compares and commits; Operator adjusts controls. Roles may change within one session.

The main loop is Import -> Intent -> Analyze -> Plan -> Execute -> Preview -> Compare -> Approve/Refine -> Export. Use plain descriptions of intended edits and actual tool parameters. Progress distinguishes analysis, rendering and download; all long jobs have cancellation. A candidate is clearly labeled unapproved. Approval is a deliberate action, not a timeout or navigation side effect. Refine and reject preserve the prior approved revision.

Manual sliders show units and reset affordance; gestures produce preview then one undoable commit. Offer numeric entry for precise changes. Compare includes hold/split/toggle and accessible labeled state. History explains AI batches and exposes individual tools. Advisor suggestions have reason, expected effect and uncertainty; applying a suggestion opens/uses a manual tool and requires a user action.

No unsupported capability masquerades as a loading spinner. Explain task unavailable, missing pack, insufficient memory and offline state distinctly. Preserve user intent after failure. Avoid mandatory onboarding, account creation or upsell before first local edit. Trial/license status may explain restrictions, but never blocks reopening or exporting the last approved project for data recovery.

Minimum targets: platform-recommended touch sizes, dynamic text, screen-reader labels/value announcements, sufficient contrast, no color-only status, reduced-motion respect, accessible alternatives to dragging masks/crop handles. Portrait/landscape and interruptions preserve project state. Phase 11 validates these on both platforms with assistive technologies.
