## Implementation audit findings resolved before certification

A: cancellation before native admission requires revocation before cancellation
(epoch cancellation is deliberately nonsticky). The adapter uses revoke -> cancel,
without modifying native approval consumption or candidate semantics. Repeated
Apply is fenced by exact review identity, attempted native proposal serial and
one active call. Coalesced cancellation prevents gesture-driven queue growth.
Late cancellation cannot relabel an already completed publication as cancelled.

A: Swift's new locked helper must not destroy an unowned AgentApproval ARC object
on native approval rejection while holding its nonrecursive owner lock. Native
approval now writes a local C token first; the owning Swift object is constructed
only after success. A stale-source approval rejection test covers this failure
path. This is adapter lifetime/marshalling correctness, with no change to native
approval authority, format, binding or consumption.

Receipt shape/version/reserved/consumed and hex identities are checked before
completion, and source identity is compared with the reviewed source. Malformed
receipt tests are pure transport validation, never a test execution authority.
