## Architecture and validation

Existing reference Assistance Provider -> UNTRUSTED Envelope v1 -> shared native
validation -> Structured Intent v1/reference planner or canonical Plan v1 ->
Registry v1 -> ephemeral REVIEW_READY. Both embedded paths reuse frozen validators.
No independent Kotlin/Swift parser, heuristic recipe, clamping or repair.
Eleven existing goals and exact integer semantics are unchanged. Plans retain
maximum eight ordered actions and 8192 canonical bytes. Provider metadata remains
outside Plan v1. A proposal ID is correlation only, never authority.

## Native and platform boundary

Four narrow checked C functions request, inspect current summary, copy canonical
bytes and cancel. The summary is caller-owned, 328 bytes, with up to eight typed
actions and four integer parameters per action. No new handle or execution API.
JNI and Swift transport only validated presentation data. Android Compose and
Apple SwiftUI enable Auto with explicit choices, requesting/validation states,
bounded read-only action summaries, Cancel and Dismiss. Manual Apply/tool controls
are absent in Auto; there is no Apply/Approve/Execute control for a proposal.

## Lifecycle and regression

One shared provider request per editor, no queue. Request serial, source serial,
context and repository epoch fence publication. Manual changes, undo/redo,
cancellation, mode abandonment and stop invalidate cached proposals. Late results
cannot republish. No resurrection on Auto -> Manual -> Auto. Existing stop -> join
all calls -> destroy ownership is retained. Proposal state is ephemeral.
MANUAL remains independent; AI Assist is unchanged and Use suggestion remains
navigation-only. Only explicit existing manual Apply creates manual revisions.

its serial. A result already beyond provider cancellation could therefore pass
a serial-only readiness fence. Native now also records cancellation explicitly
under the existing gate and checks it before ready publication. The bounded
regression pauses the final-serial request after validation, cancels, and proves
CANCELLED/no history/no future request admission. No counter wraps or contract
changes; cancellation remains nonsticky for later ordinary requests. Final
