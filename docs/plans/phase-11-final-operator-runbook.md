Before enabling paid/quota UI, obtain native commercial-admission/inbox compatibility
acceptance and end-to-end integration; component mocks are not purchase outcomes.
Only app-scoped test cache objects/keys may be removed in test cleanup. Never reset
system Keychain, change Apple account/team/profile/certificates or affect other apps.
Phase11 remains open; no Phases12–14 implementation or hardware provider promotion.

Backend contract detail: the subscription verifier fails closed unless an authenticated
revocation-status provider is configured. A purchase GET showing expired alone does
not prove absence of a revoke/refund. Supply real authenticated notification/status
reconciliation (for example authorized Google RTDN infrastructure), never a constant
not-revoked callback in production. Reference callbacks in tests are synthetic only.
Google requests use partial-response field masks to avoid unrelated account/order data.
Store timestamps are conservatively floored to whole UTC seconds, never rounded up.
The metadata client, backend function, SDK adapter and secure cache are components;
there is no deployed endpoint, configured catalog, live checkout UI or enabled native
commercial owner in the shipping application yet. Complete the reviewed integration
before attempting operator checkout; this runbook is setup/qualification preparation,
not a claim that existing UI performs purchases. No real-money transaction authorized.
