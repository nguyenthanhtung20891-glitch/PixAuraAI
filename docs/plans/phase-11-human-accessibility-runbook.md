# Phase 11 operator accessibility runbook — NOT OBSERVED

No row is preapproved. Automation/source semantics do not constitute VoiceOver,
TalkBack, contrast, focus or alternative-input human observations. DH Metal PASS
is unrelated. Phase11 remains open, Phase12 not authorized.

## Prepare and identify each actual run

Record operator/date, exact installed source and completed CI, physical model/OS,
app language, text/display scale, light/dark, assistive-service version/settings,
input device, radio state and synthetic input hash/dimensions. Record device
cohort rationale separately. Do not upload personal photos, tokens or device IDs.

On iOS, the operator enables VoiceOver in Settings > Accessibility > VoiceOver;
set English/Vietnamese app language through the available app/system language
control, then record the exact route/version. Under Display & Text Size/Larger
Text, test normal and largest supported accessibility size; repeat light/dark.
On Android, enable TalkBack via Settings > Accessibility (OEM route varies), set
app/system English/Vietnamese and normal/largest supported font/display scale;
repeat light/dark. Record actual OEM controls. Do not change developer signing,
accounts or global services through agent automation.

Use screen-reader next/previous navigation and activate the announced control,
not a sighted coordinate tap. Record spoken label/value/unit/hint, enabled/selected
state, focus sequence and return focus. Repeat with an actual external keyboard,
Switch Access or platform-supported alternative route; record keys/actions used.

## Execute these journeys in every required configuration

1. Launch Home. Read privacy/empty state. Open Manual, navigate to Open Photo,
   open the system picker, cancel, reopen and choose a synthetic JPEG/PNG. Record
   focus returning to the invoking control, import errors and recovery. Exercise
   deny/revoke only through operator-authorized OS controls; restore settings.
2. Navigate category and Exposure. Verify selected tool and units/bounds. Change
   through accessible adjustment actions, then Cancel: history unchanged. Repeat
   and explicitly Apply: one ordinary revision. Announce Undo/Redo availability,
   activate each and verify the displayed ordinary revision/content.
3. Open Assist, select a goal, request, cancel/dismiss, request again and choose
   guidance. Verify guidance itself never applies an edit. Set a manual value,
   Apply; verify Manual is reachable after cancellation/error.
4. Open Auto, request proposal. Read provenance, exact actions/order/raw units/
   bounds/geometry warning. Edit a value, remove/move and restore an action; read
   updated inspection. Preview is labelled disposable. Exercise Before/After,
   zoom/pan/split or geometry-fit fallback; never treat preview as publication.
5. Reject/abandon review, switch mode, background/foreground and reopen. Old
   approval must not return. Request a fresh review and explicitly Apply once;
   ordinary history advances once. Verify result review, previous/current content,
   Undo/Redo and Back to editing. Navigate through every fixed header control.
6. Open Export. Select JPEG/quality then PNG; file/Photos/share actions remain
   reachable at maximum text. Cancel/deny, verify error announcement/recovery and
   unchanged history. An opened share sheet is not evidence of delivery. Record
   actual destination delivery separately, with synthetic data.
7. For every modal and failure, record initial focus, escape/back operation,
   announcement timing and returned focus. Check no traps, clipped labels,
   indistinguishable states or solely color-dependent meaning. Measure actual
   contrast pairs/tool/settings; do not infer ratios from screenshots alone.
